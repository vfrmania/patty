# 🎯 Concours ATSEM — Somme (voie externe)

Site web de préparation au concours d'Agent Territorial Spécialisé des Écoles Maternelles (ATSEM), organisé par le Centre de gestion de la Somme.

## 🌐 Accès au site

Une fois GitHub Pages activé : **https://vfrmania.github.io/patty/**

## 📖 Contenu

- **Guide de préparation** : calendrier officiel 2027, épreuves (QCM + oral), planning de révision 4 h/semaine, les 10 thèmes à maîtriser, stratégie QCM, préparation de l'entretien (coefficient 2), ressources officielles
- **QCM interactif** (25 questions au format de l'épreuve) :
  - 🧪 Mode examen blanc : 20 questions, 45 minutes, barème officiel avec pénalités (+1 / −0,5 / 0), note éliminatoire ≤ 5/20, historique des scores
  - 📚 Mode entraînement par thème : correction immédiate et explication pédagogique
